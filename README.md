# Anjan Digital Services website

Static website for GitHub Pages. Open `index.html` in a browser for a basic local preview, or use VS Code Live Server for a closer local preview.

## Pages
- `index.html` — home
- `about.html` — about
- `services.html` — all 30 approved service categories
- `downloads.html` — searchable/filterable catalogue of 140 existing PDF files
- `contact.html` — WhatsApp enquiry form (opens WhatsApp; does not submit to a website backend)
- `faq.html`, `privacy.html`, `terms.html` — FAQ and policy pages

## Publish with GitHub Pages
1. Extract this ZIP.
2. Open the extracted project folder in VS Code.
3. Review the site locally, including the Downloads page and WhatsApp links.
4. Commit and push the files to the `main` branch of `anjandasphotos/anjan-digital-services`.
5. In GitHub, open **Settings → Pages** and confirm the published branch/folder matches your existing configuration.
6. Wait for the Pages deployment to finish, then test the live site on mobile and desktop.
